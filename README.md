# valrqr.github.io

Page portfolio de Valentin Rouquier, publiée sur https://valrqr.github.io (GitHub Pages).

Une seule page HTML, sans étape de build, bilingue FR/EN (`?lang=en` pour forcer l'anglais).
Style inspiré d'Excalidraw : contours dessinés avec Rough.js (licence MIT, `js/rough.js`), police Nunito (SIL Open Font License) hébergée dans `fonts/`.
